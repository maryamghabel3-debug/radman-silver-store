## SECTION 7 — پاسخ‌های خطرناک (`Red Flags`)

> ⚠️ **اگر این پاسخ‌ها را شنیدید، قبل از خرید توقف کنید:**

- «API اصولاً باید کار کند» بدون توضیح WAF
- «منابع نامحدود» بدون عدد دقیق
- عدم امکان Whitelist فایروال
- عدم اتصال خروجی به سایت قدیمی
- Cron فقط ساعتی یا روزانه
- نبود دانلود بکاپ کامل
- Restore اجباری کل اکانت
- نبود Addon Domain
- IP غیرثابت وقتی API قدیمی نیاز به Whitelist دارد
- مسدود شدن Callback درگاه سفارشی
- Suspend خودکار بدون هشدار
