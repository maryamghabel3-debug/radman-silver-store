# LEGACY API FIELD INVENTORY & AVAILABILITY CLASSIFICATION (`LEGACY-API-FIELD-MAP.md`)

This document provides an exhaustive 25-field audit and reliability classification for data extracted from `noghrehmashhad.ir`.

---

## 1. Field Classification Standard

- **`AVAILABLE_AND_RELIABLE`:** Field is present in feed, structured, and can be synchronized programmatically.
- **`AVAILABLE_BUT_UNVERIFIED`:** Field is present in feed but requires human review or validation before publishing.
- **`AVAILABLE_BUT_MANUAL`:** Field is unstructured or embedded in HTML tables; requires regex parsing or manual audit.
- **`NOT_AVAILABLE`:** Field is absent from legacy API; must be generated by RADMAN SILVER store logic.
- **`UNKNOWN`:** Field availability cannot be confirmed from outside domestic Iranian IP routing.

---

## 2. Comprehensive 25-Field Inventory Matrix

| Product Attribute Field | Expected Legacy Key | Classification | Operational Notes & Sync Strategy |

| **1. Product ID** | `id` | `AVAILABLE_AND_RELIABLE` | Numeric primary key (`e.g., 3639`); mapped to `_legacy_store_id` |

| **7. Tags** | `tags` | `AVAILABLE_BUT_UNVERIFIED` | Search tags; imported as product tags |
| **8. SKU** | `sku` | `NOT_AVAILABLE` | Legacy store lacks standard SKU; Radman generates `RAD-[CAT]-[GENDER]-[ID]` |
