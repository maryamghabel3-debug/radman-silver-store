# RADMAN SILVER 925 — WooCommerce E-Commerce Store (`radman-silver-store`)

Welcome to the official e-commerce repository for **RADMAN SILVER 925** (`radmansilver.ir`, `radman925.ir` — Sterling Silver Maison).

---

## 1. Store Architecture & Technology Stack

- **CMS & Commerce Engine:** WordPress 6.x + WooCommerce
- **Theme:** Blocksy Child Theme (Luxury Jewelry Maison custom dark/ivory styling)
- **Brand Identity Reference:** [brand-assets/radman-silver](https://github.com/maryamghabel3-debug/brand-assets/tree/main/radman-silver)
  - English Canonical Logo Suite: `APPROVED/`
  - Persian Final Approved Logo Suite: `APPROVED-FA/` (`Estedad Bold`, `S2` sizing, `T2` tagline `اصالت در جزئیات` / `T0` minimal header logo)
- **Primary Color Palette:**
  - Background: Matte Black (`#0B0B0E`)
  - Artwork & Text: Ivory (`#FAF7F2`)
