# Prompts Used — Website Showcase Pilot (product 211, 2026-08-29)

All six styles were generated with the agent's native image-editing capability using
`cleaned/product-211-sku-NM-3603-featured-attachment-212.webp` (1600×1600) as the only
product reference image. Common structure of every prompt:

1. Role: ultra-realistic professional ecommerce photograph for RADMAN SILVER 925.
2. Product identity paragraph — describes the exact ring from the reference
   (oval purple amethyst cabochon, crown of pointed silver prongs, beaded bezel,
   ornate floral hand-engraved tapering band) and requires preservation of shape,
   color, internal stone character, engravings, proportions; "same product, not a
   redesign."
3. Angle lock — keep the reference camera angle (slightly above, front three-quarter)
   so no unseen geometry is invented.
4. Scene paragraph per style (velvet / black glass / ivory travertine / graphite
   slate / brown leather / museum gradient) with the lighting, contact shadow and
   reflection direction from the task brief.
5. Composition — square 1:1, ring ≈ 60% of frame, fully visible, clean margins.
6. Global negative clause (from the brief): different ring, redesigned ring, modified
   band, altered gemstone, changed stone color/pattern, simplified inclusions,
   invented engraving, missing inscription, extra/missing stones, fake jewelry,
   plastic metal, excessive shine, floating ring, cropped ring, rough cutout, pasted
   object, halo, mismatched shadows, impossible reflection, human hand, fingers,
   mannequin, text, price, watermark, old logo, Radman logo, pink background, purple
   background, clutter, flowers, fantasy effects, CGI appearance.

Per-style scene sentences (abridged):
1. **Dark charcoal velvet** — premium velvet nap, subtle folds, soft directional key,
   restrained warm-gold rim from the left, realistic contact shadow, no crushed blacks.
2. **Black glass** — polished glass, restrained physically-accurate reflection beneath
   the contact point matching only visible geometry, cool silver highlights + subtle
   warm accent, no mirror exaggeration.
3. **Ivory stone** — warm ivory travertine, fine texture, bright controlled key, soft
   shadow, no clipping, no yellow cast, no busy marble.
4. **Graphite slate** — subtle graphite grain, cinematic soft side light, restrained
   shadow, rugged-premium, texture never covering product details.
5. **Dark brown leather** — subtle leather grain, warm directional key, deep
   brown/charcoal palette, restrained golden highlights, no accessories/brands.
6. **Museum gradient** — smooth dark grey→charcoal gradient, controlled spotlight with
   soft falloff, flat matte surface, no stand unless physically necessary.

No text overlays were generated; no logos; no post-generation compositing.
Native resolution 1024×1024 → Lanczos upscale to 1600×1600 (spec canvas), exported as
WebP q93 + PNG, sRGB.
